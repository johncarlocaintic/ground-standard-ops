Never use em dashes (—) anywhere. Use a period, comma, colon, parentheses, or a hyphen-with-spaces ( - ) instead.

**Why:** User rule set 2026-04-23. Likely a stylistic/brand preference; em dashes read as AI-generated to many readers.

**How to apply:** Applies to every text output: chat replies, drafted Slack/ClickUp/Gmail messages, doc writing, commit messages, code comments. Also applies when reformatting something the user wrote if rewriting is the task. Do not apply when quoting source material verbatim.
