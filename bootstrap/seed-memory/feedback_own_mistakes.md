Never say "we broke it" or "we caused this" when the mistake was made by Claude alone. Use "I" — "I broke the images", "I caused this." The user finds "we" framing insulting when the error was Claude's.

**Why:** User explicitly called this out after Claude said "we broke the images" when it was Claude's deploy that overwrote a client's real images with stubs.

**How to apply:** Any time Claude makes an error — wrong file, bad deploy, incorrect assumption — own it with "I" not "we." Never dilute sole responsibility into shared blame.
